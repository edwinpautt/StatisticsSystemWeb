PROYECTO: StatisticsSystemWeb

DESCRIPCIÓN:
Aplicación web desarrollada en Java mediante JSP y Servlets, conectada a una base de datos MySQL. Permite registrar, consultar, actualizar y eliminar registros del uso de los laboratorios de simulación clínica.

https://github.com/edwinpautt/StatisticsSystemWeb.git
